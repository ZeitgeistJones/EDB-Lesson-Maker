# Production Playbook v1.0 — Sunbeam School A1 Units

## Accepted Reusable Components

| Component | Acceptance rule |
|---|---|
| Character sheet | Maya, Leo, Jun, Nia, and Pip retain stable silhouette, clothing palette, facial style, and friendly scale. |
| Header | Use compact `UNIT 01 • LNN` identifier, large lesson title, time chip, and ten-dot progress row. |
| Scene title | When a school-scene background includes bunting, place a navy title-safe ribbon in the clear band below the objective and above task content. |
| Task panel | Use one dominant learner job, an imperative title, large high-contrast copy, and a visible step number. |
| Interaction token | Use padded, rounded, navy-outlined, transparent assets; make source and destination state explicit in the handoff. |
| Pair exchange | Show two roles, a turn direction, exact frames, and a switch state. |
| Production proof | State the minimum exact language evidence and a teacher/peer check before celebrating completion. |
| Culminating language arc | Keep speech-step labels in a fixed title-safe arc around—not on top of—the central performance area. |

## QA Gates

1. Confirm 10 board files and correct sequential naming per lesson.
2. Confirm every declared vocabulary item has an unambiguous visual introduction before production.
3. Confirm every sentence frame is grammatically valid for all supplied learner choices.
4. Confirm no critical title, task instruction, language proof, or moveable source overlaps another core element.
5. Confirm each lesson has a final observable production plus a closure tied to it.
6. Confirm one dominant palette register, unified characters, and the title-safe ribbon when school bunting is used.

## Known Exclusions

Do not reuse an activity solely because it exists in an earlier lesson. Do not place target vocabulary as pre-labelled answers on an inferential matching board. Do not treat static PNGs as native functional boards; configure interactions in the board editor.
