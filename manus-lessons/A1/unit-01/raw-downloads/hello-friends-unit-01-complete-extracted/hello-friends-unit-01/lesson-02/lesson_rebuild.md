# Lesson 02 — My Name Is…

**CEFR:** A1  
**Topic:** My name is…  
**Communicative objective:** Introduce yourself with a clear name sentence.  
**Target vocabulary:** name, I, am, my  
**Target language:** My name is ___. / I’m ___.

> **Implementation note:** Each PNG is a finished visual board. Native dragging, snapping, click reveals, editable text entry, and state persistence must be configured in the teaching board editor; static images do not claim to provide those functions.

## Import Order

1. Import the numbered boards as locked visual reference/background layers.
2. Add the named files in `assets/clean/` as separate objects where a board calls for a moveable source.
3. Recreate language that needs to be edited as board text, preserving the exact target form shown above.
4. Configure the stated snap, reveal, or persistence condition and test both starter and success states.
5. Carry the completed production state into the closure where the platform supports it; otherwise use the designed celebration state as the explicit result.
